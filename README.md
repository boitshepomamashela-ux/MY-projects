# Coach Cathy

Marketing website for **Coach Cathy** (Cathy Mphirima) — youth coach, NLP practitioner, and speaker.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Pages

- `/` — Home (hero, about, services, media, events, book, contact)
- `/coaching`
- `/facilitation`
- `/mcing`
- `/speaking`
